# BigMart Retail Analytics Dashboard

An interactive Power BI dashboard designed to analyze BigMart product performance, outlet distribution, pricing, product visibility, and retail business insights.

## Project Overview

This project presents an interactive retail analytics solution developed using Microsoft Power BI.

The dashboard provides a consolidated view of product and outlet performance through KPIs, category analysis, outlet analysis, pricing metrics, product visibility, and interactive filters.

## Project Objective

The objective of this project is to transform retail product and outlet data into meaningful business insights using data cleaning, transformation, analysis, and visualization.

The dashboard helps analyze:

- Product category distribution
- Product pricing and MRP
- Product visibility
- Product weight
- Fat content distribution
- Outlet type and outlet size
- Outlet location distribution
- Outlet establishment trends
- Product-level details

## Dashboard Pages

### 1. Executive Dashboard

Provides an overall summary of BigMart products and outlets using key performance indicators and visualizations.

Key metrics include:

- Total Products
- Total Outlets
- Average MRP
- Product Categories
- Average Visibility
- Average Weight

### 2. Product Analytics Dashboard

Analyzes product-level characteristics including:

- Average MRP by product category
- Average shelf visibility
- Product mix by fat content
- Average weight by category
- Top product categories
- Product-level summary

### 3. Outlet Analytics Dashboard

Analyzes outlet characteristics including:

- Products by outlet type
- Average MRP by outlet type
- Outlet distribution by location type
- Outlet establishment trend
- Outlet size distribution
- Outlet-level summary

### 4. Business Insights

The dashboard provides business insights and recommendations based on the analysis.

Key insights include:

- Snack Foods is the largest product category.
- Low Fat products account for approximately 65% of the inventory.
- Medium-sized outlets contain the highest number of products.
- Supermarket Type1 has the largest product assortment.
- Average product price varies across categories.
- Product visibility varies across categories.
- Tier 3 locations contain the highest number of products.
- Products are distributed across 16 categories and 10 outlets.

### 5. Product Details

Provides detailed analysis for individual product categories, including:

- Highest MRP
- Lowest MRP
- Average MRP
- Average visibility
- Average weight
- Fat-content comparison
- Product-level details

## Business Recommendations

Based on the dashboard analysis:

- Increase inventory for high-demand categories.
- Improve shelf visibility for low-performing categories.
- Expand product assortment in medium-sized outlets.
- Focus promotional campaigns on Tier 3 locations.
- Maintain a balanced mix of Low Fat and Regular products.
- Monitor high-MRP categories for pricing strategy.

## How to Use

1. Download or clone this repository.
2. Open the `.pbix` file from the `PowerBI` folder using Microsoft Power BI Desktop.
3. If required, update the dataset source path.
4. Refresh the data.
5. Use the available filters to explore product and outlet performance.
6. Navigate through the dashboard pages to explore detailed insights.
